# Snipify

Snip your playlist into perfection! Snipify is a web app that allows users to remove tracks from their Spotify playlists by simply swiping. Effortlessly curate your playlists and get rid of unwanted songs with ease.

## Features

- **Swipe to Remove**: Easily remove tracks from your Spotify playlist with a swipe action.
- **Spotify Integration**: Seamlessly integrates with your Spotify account to access and manage your playlists.
- **User-Friendly Interface**: Intuitive and minimalistic design for smooth playlist management.
- **Track Streaming**: As you swipe the track's audio will play

## Installation
1. Install deps
```bash
   npm i
```

2. Create a .env file in the root directory and add server URL:
```bash
VITE_SERVER_URL=https://floating-journey-45917-b9d3c6ebc783.herokuapp.com
```

3. Start client
```bash
npm run dev
```
